02 AI engineering

Nia – an assistant inside Nudge

A chat assistant and tool-calling agent built into the Nudge portal. It explains the product, looks up the signed-in user's data, opens pages and runs confirmed actions, always acting as that user.

Three-step agent

  • Triage works out the intent; an actor calls tools (max 6 steps); a reply step keeps only facts backed by tool results.
  • Model fallback chain with retries and timeouts.
  • Rewritten from a Python sidecar into C# inside the .NET 8 API.

Prompt engineering

  • A separate system prompt for each step, with grounding rules and prompt-budget caps.
  • BM25 search over the product's help content, so answers quote real docs.
  • Common questions answered without calling the model.

Safe by design

  • Every tool call runs as the signed-in user, so normal permissions still apply.
  • Destructive actions need confirmation; per-user rate limits.
  • Live streamed replies in an accessible Angular chat panel.

I use Claude Code day to day on the Nudge codebase (22 sessions so far), including the Nia rewrite and the Angular 21 upgrade.
